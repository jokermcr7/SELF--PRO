# Telegram Self Platform (Telethon + Postgres) — Railway

ربات مدیریت + سلف چندکاربره. کاربر شماره‌اش رو به ربات می‌ده، کد رو با کیپد عددی می‌زنه و سلف روی اکانتش فعال میشه.

## قابلیت‌ها
- **ورود:** دکمه‌ی ارسال خودکار شماره یا تایپ دستی (هر فرمتی: `0912...`, `+98912...`, `0098912...`, ارقام فارسی). کد با دکمه‌های عددی یا تایپی (هر فرمتی). پشتیبانی از رمز دو مرحله‌ای.
- **`.panel` در هر چتی** → پنل با دکمه‌ها (روشن/خاموش کردن امکانات، تمدید، راهنما)
- **ابزار:** متن (bold/mono/spoiler/…)، ۶ فونت، تایپ انیمیشنی، ماشین‌حساب، ترجمه، تبدیل متن به صدا، ارز و کریپتو، هواشناسی، اوقات شرعی، دانلودر ویدیو، یادآور، رمز تصادفی، تاس/دارت/بسکتبال
- **ضد حذف و ادیت** پیام‌های پیوی + **ذخیره‌ی تایمردار** (میره Saved Messages)
- **ساعت شمسی** کنار اسم، **منشی خودکار**، **پاسخ کلمه‌ای**
- **چت:** ذخیره، حذف پیام‌های خودت، پین، بلاک، آمار، آیدی/اطلاعات
- **الماس 💎** (کامل):
  - **مالک (`ADMIN_IDS`) الماس و اشتراک نامحدود دارد** (هیچ‌وقت کم نمیشه، توی بازی‌ها هم کسر نمیشه).
  - هدیه‌ی **۱۰۰ الماس** برای اولین ورود به ربات (`/start`) — فقط یک‌بار.
  - **هر ورود سلف به اکانت = ۳۰ الماس**؛ موجودی کمتر از ۳۰ → سلف وارد اکانت نمیشه (کسر بعد از ورود موفق؛ اگه سلف بالا نیاد برمی‌گرده).
  - **خرید الماس:** دکمه‌ی «💳 خرید الماس» ← تعداد دلخواه رو با دکمه‌های عددی می‌زنه و **قیمت همون لحظه** نشون داده میشه (۱۵۰۰ الماس = ۴۰,۰۰۰ تومان) ← «تایید» ← فاکتور با شماره کارت و نام صاحب کارت (`CARD_NUMBER` / `CARD_OWNER`) ← «✅ پرداخت کردم» ← «🧾 ارسال رسید» ← عکس رسید برای ادمین میاد با دکمه‌ی «تایید و شارژ / رد» ← بعد از تایید الماس خودکار به کاربر منتقل میشه.
  - انتقال: داخل گروه روی پیام کاربر **ریپلای** کن و بنویس `انتقال 25` (یا `/give 25`، یا `.give 25` از سلف).
  - هدیه‌ی روزانه (`/daily`)، کد هدیه (`/code xxx`)، دعوت دوستان (لینک اختصاصی، ۵۰ الماس به‌ازای هر نفر)، تاریخچه‌ی تراکنش‌ها (`/history`)، برترین‌ها.
  - ادمین: `/addd id n` شارژ | `/take id n` کسر | `/bal id` موجودی | `/gift کد مقدار تعداد` ساخت کد هدیه | `/bc متن` پیام همگانی | `/users`
- **بازی فقط در گپ مخصوص:** `بازی 44` → پیام بازی با بنر و دکمه‌های رنگی (پیوستن / لغو بازی / بازی با بات). سازنده، تعداد بازیکنان، مقدار، جایزه‌ی برنده و مالیات (۵٪) نمایش داده میشه. با پیوستن نفر دوم (یا «بازی با بات») نتیجه فوری و منصفانه (شانس برابر) روی همون پیام ثبت میشه. `بازی 44 3` → سه‌نفره. `موجودی`، `/dice /coin /slot /guess`، `/daily`، `/top`
- **همه‌ی دستورهای سلف فارسی‌ان** (مثلاً `.آیدی` `.پنل` `.ترجمه` `.موجودی`؛ نام انگلیسی قبلی هم مخفی کار می‌کنه). ۶۷ قابلیت در ۷ بخش (عمومی، متن، ابزار، چت و گروه، اتوماسیون، سرگرمی، الماس) با **راهنمای دکمه‌ای**: ربات ← «📖 همه‌ی دستورها» یا `.پنل` ← «📖 راهنما» ← بخش ← هر دستور = توضیح + طرز استفاده + (برای بعضی) دکمه‌ی اجرا. هر بخش ۶ تا ۶ تا صفحه‌بندی میشه. فایل `catalog.py` تنها منبع این لیسته.
- **قابلیت‌های ویژه:** `.زمانبندی`، `.شمارش`، `.کیوآر`، `.درحال_تایپ`، `.پاکسازی`، `.بیو`، `.اسم`، `.تاریخ`، `.یادداشت`، `.تخریب`، `.کپی`، `.معکوس`، `.من`، `.سکه`، `.هک`، `.عشق`، `.بپرس`، `.دعوت` و دستورهای الماس (`.موجودی .هدیه .انتقال .برترین .خرید`)

## ظاهر جدید (مثل ویدیو)
- **/start:** بنر + متن خوش‌آمد + دکمه‌های رنگی (مدیریت سلف، وضعیت زمان|الماس، خرید الماس، حساب کاربری، کد الماس، زیر مجموعه، پشتیبانی، چنل/گپ).
- **ورود:** مدیریت سلف ← فعالسازی سلف ← «ارسال شماره تلفن» ← کیپد شیشه‌ای رنگی (تایید کردن / پاک کردن / انصراف) ← «سلف با موفقیت فعال و روشن شد».
- **`.پنل`:** پنل با بنر ← «مدیریت سلف» (راهنمای ۷ صفحه‌ای، ۲ ستون سبز، تب‌های ۱ تا ۷) / «حساب کاربری» (اسم، آیدی، یوزرنیم، الماس، انقضا) / «بستن پنل».
- داخل صفحه‌ی هر دستور: توضیح + طرز استفاده؛ برای منشی، ضدحذف، تایمردار، پاسخ کلمات، ساعت و مدیریت سلف دکمه‌ی **روشن ⟨✓⟩ / خاموش ⟨✗⟩** هست. `.مدیریت_سلف خاموش` کل سلف رو متوقف می‌کنه.
- متغیرهای اختیاری جدید: `CHANNEL_USERNAME` (دکمه‌ی چنل ما)، `SUPPORT_GROUP_LINK` (گپ پشتیبانی)، `SUPPORT_USERNAME` (پشتیبانی).

## راه‌اندازی
1. https://my.telegram.org ← `API_ID` و `API_HASH`
2. @BotFather: ربات بساز. سپس
   - `/setinline` → روشن (لازمه برای `.panel`)
   - `/setprivacy` → **Disable** (تا ربات پیام‌های گروه مثل «موجودی» رو ببینه)
3. ربات رو به گروه بازی اضافه کن (ترجیحاً ادمین) و داخل گروه با اکانت ادمین بزن `/setgame`
4. کلید رمزنگاری بساز: `python -c "from cryptography.fernet import Fernet;print(Fernet.generate_key().decode())"`
5. Railway: New Project → Deploy from GitHub → Add **PostgreSQL**
6. Variables رو از `.env.example` ست کن (`ENCRYPT_KEY` رو **گم نکن**، بدونش sessionها قابل خوندن نیستن)
7. ادمین: `/addd <user_id> <تعداد>` برای شارژ الماس، `/users` آمار. شماره کارت فروش با `CARD_NUMBER` و `CARD_OWNER` تنظیم میشه

## نکته‌ها
- فقط روی **همون اکانتی** که با ربات حرف می‌زنه می‌شه سلف ساخت.
- «خروج و حذف سلف» نشست رو از دیتابیس پاک می‌کنه و از تلگرام هم خارج می‌کنه.
- بازی‌های الماسی فقط سرگرمیه. برداشت/تبدیل الماس به پول نقد نذار (می‌شه قمار).
- دکمه‌های رنگی (سبز/قرمز/آبی) با Bot API فرستاده میشن؛ اگه تلگرام نسخه‌ی کلاینت قدیمی باشه دکمه‌ها بدون رنگ دیده میشن.
- یادآورها توی حافظه‌ان و با ری‌استارت سرویس از بین می‌رن.
- دانلودر اینستاگرام ممکنه بدون کوکی کار نکنه.
