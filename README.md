# MMD Self (Telethon + Postgres) — Railway

## الماس
- قیمت: ۱۵۰۰ الماس = ۴۰,۰۰۰ تومان (هر الماس ≈ ۲۶.۷ تومان)
- هدیه‌ی اولین `/start`: ۱۰۰ الماس
- هر ورود سلف: ۳۰ الماس (بدون الماس، سلف وارد اکانت نمیشه)
- خرید الماس به تعداد دلخواه (دکمه‌ی «خرید الماس»): کاربر تعداد رو می‌نویسه، مبلغ حساب می‌شه، رسید می‌فرسته و ادمین با یک دکمه تایید می‌کنه
- ادمین‌ها (`ADMIN_IDS`) الماس نامحدود دارن
- `انتقال 25` با ریپلای = انتقال الماس
- شارژ دستی: `/addd <user_id> <تعداد>`

## بازی (فقط داخل گپ مخصوص؛ با `/setgame` توسط ادمین تعیین میشه)
`بازی 50` دونفره (پیوستن / لغو / بازی با ربات) — `بازی 3 50` سه‌نفره
`تاس` `دارت` `بولینگ` دوئل با ربات — `سکه` — `رولت` — `موجودی` — `روزانه` — `برترین`
همه‌ی بازی‌ها شانس برابر دارن؛ مالیات ۵٪ از جایزه کسر میشه.

## ساعت زنده
`.clock on|off` `.clock name|bio|both` `.clockfont 3` یا از پنل. دقیقاً سر هر دقیقه آپدیت می‌شه.

## ایموجی پرمیوم (سلف)
`.pe add` + ایموجی پرمیوم → ثبت؛ از اون به بعد ایموجی معمولی خودکار با پرمیوم ادیت میشه.
`.pe add 😀 ✨` ثبت دستی | `.pe list` | `.pe del 😀` | `.pe clear` | `.pe on|off`
(اکانت باید پریمیوم باشه.)

## راه‌اندازی
BotFather: `/setinline` روشن، `/setprivacy` → Disable. ربات رو توی گروه بازی اضافه کن و `/setgame` بزن.
متغیرها رو از `.env.example` توی Railway ست کن و PostgreSQL اضافه کن.
